# Xiaomi14 4K120

KernelSU / Magisk module.

Experimental 4K120 video recording support for the stock Xiaomi 14 camera. Compatible with houji and the supported sunny OVX9000 wide / wide_ii sensor tables.

Not yet tested on a phone.

## Install

Install the module through your root manager and reboot.

To restore stock, disable or remove the module and reboot.
