# Xiaomi14 4K120

KernelSU / Magisk module.

Adds 4K120 video recording to the stock Xiaomi 14 camera. Compatible with houji and the supported sunny OVX9000 wide / wide_ii sensor tables.

Tested on Android 16.

## Install

[Download from releases](https://github.com/Picters/Xiaomi14-4K120-Unlocker/releases), install it through your root manager and reboot.

To restore stock, disable or remove the module and reboot.
